# Career Day Scavenger Hunt 2026

## Overview
A retro terminal-themed scavenger hunt web application designed for Career Day 2026. This interactive game challenges participants to solve puzzles and questions at different stations while navigating through a nostalgic hacker-style interface.

## Features
- **Retro Terminal UI**: Green-on-black CRT-style interface with scanline effects
- **Multi-Station Gameplay**: Navigate through different career-related stations
- **Interactive Questions**: Answer questions and receive real-time feedback
- **Progress Tracking**: Track your completion status throughout the scavenger hunt
- **Responsive Design**: Works on desktop and mobile devices
- **Dynamic Styling**: Glowing text effects, animations, and visual feedback

## Project Structure
```
├── index.html      # Main application file (HTML + CSS + JavaScript)
└── README.md       # Project documentation
```

## How to Use
1. Open `index.html` in a web browser
2. Read the instructions on the landing page
3. Follow the QR code or link to visit different stations
4. Answer the questions at each station
5. Submit your answers to progress through the scavenger hunt

## Technology Stack
- HTML5
- CSS3 (with animations and effects)
- Vanilla JavaScript

## Customization
The application can be customized by:
- Modifying station questions and answers in the JavaScript code
- Adjusting colors by changing the green (`#0f0`) hex values
- Adding or removing stations as needed

## Browser Compatibility
Works on all modern browsers:
- Chrome/Edge
- Firefox
- Safari

## Notes
- This is a single-file application for easy deployment
- All styling and logic are contained within `index.html`
- No external dependencies required
